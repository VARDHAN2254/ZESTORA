# @zestora/ui

Shared UI component library for ZESTORA.

Contains reusable presentation components:
- `components/` - Buttons, Inputs, Cards, Badges
- `layouts/` - Shells, Grids, Containers
- `forms/` - Form inputs, labels, validation wrappers
- `feedback/` - Modals, Toasts, Alerts, Progress
- `navigation/` - Navbars, Sidebars, Tabs, Breadcrumbs
